Core Features

What This System Does

Real Time Recognition

21 hand landmarks extracted per frame via MediaPipe. Stabilization buffer ensures accurate, jitter free character detection.

Multi Language Output

Recognized text is translated to Hindi or Gujarati on demand. Native TTS speaks the output in the selected language.

Word Suggestions

Offline NLP via NLTK bigram corpus. As you sign letters, the system predicts word completions and next word suggestions.

Performance Dashboard

Live confidence score, characters per minute, hand detection rate, and full session statistics tracked in real time.

Word & Sentence Builder

Space gesture separates words, full stop gesture completes sentences. Each word is spoken aloud as it is formed.

Random Forest Model

Scikit-learn Random Forest trained on a custom 38 class ASL dataset. Runs at inference in milliseconds per frame.

Guide

How to Use

01

Setup Environment

Create a conda environment with Python 3.11 and install all dependencies including the new web stack.

02

Launch the Server

Run the Flask server. Open http://localhost:5000 in your browser. Ensure your webcam is connected and accessible.

03

Navigate to Live

Click the Live tab in the navigation. The webcam feed will start automatically. Allow camera permissions if prompted by your browser.

Best results in good lighting with a plain background behind your hand.
04

Sign Letters

Hold an ASL letter sign steady in front of the camera. The system requires the same sign for ~1 second before registering. Current sign and confidence appear on screen.

Use the Space gesture to complete a word, Full stop to end a sentence.
05

Use Word Suggestions

As you sign letters, the system predicts word completions using NLTK's Brown corpus bigrams. Click any suggestion pill to instantly fill the current word.

06

Translate & Speak

Select Hindi or Gujarati from the language switcher, then click Translate. Click Speak to hear the output in the selected language via text to speech.

Reference

Special Gestures

Space

Completes the current word, adds it to the sentence, and speaks it aloud.

Full Stop ( . )

Closes the current word and ends the sentence with a period.

Reset Button

Clears all current word, sentence, and session statistics instantly.

Pause Button

Freezes recognition without closing the camera feed. Useful for breaks.
